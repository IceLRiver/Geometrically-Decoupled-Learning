# Current model settings

TimeFormer: Z. Liu et al., *TimeFormer: Transformer with attention modulation empowered by temporal characteristics for time series forecasting*, Expert Systems with Applications 307 (2026) 131040. Formal source: https://www.sciencedirect.com/science/article/pii/S0957417425046548 . The implementation retains channel-independent multiscale CNN embeddings, within/between-patch momentum attention, post-softmax exponential decay and causal masking. A six-state task projection replaces the forecasting target. One attention head, widths 16/32, one/two scales and decay 0.1 are tested. AdamW uses learning rate .001, weight decay .0001, batch 1024, maximum 150 epochs, patience 25 and seed 42. The simulation width-32/two-scale candidate is adaptively pruned at epoch 91 using validation, while its best checkpoint remains eligible for training-only ridge head calibration. FP64 execution casts temporal distances before the exponential; training-only heads are refitted in this consistent precision. This is a task reimplementation, not original-author orbit software.

New GDL candidates use observation-only features. Public/real residual heads add scalar range and conditional velocity corrections using periodic-head features and observed kinematic terms, optionally with quadratic products. Simulation heads use a frozen original encoder, an observed-frame raw-input skip and scalar range-rate reconstruction `v = Rdot + rho Ldot + rhodot L`. Width-128 heads use batch 1024, weight decay .0001 and seed 42, with staged fitting: initial .001 (up to 250 epochs), raw-input extension .0003 (up to 250), velocity warmup 20 and joint .0001 (up to 100, velocity weight 1000), then .00005 for 80 epochs (velocity weight 10000). Training-only affine fits are validation-selected. The chosen model must not exceed either previous validation error and minimizes the normalized sum among eligible candidates. Test results do not select it.

Other comparison methods, their saved weights and the six controlled ablations remain frozen. Current source-specific coefficients and validation records accompany the release. Counts include active learned coefficients used in inference, including frozen pretrained tensors; per-arc fitted coefficients are distinguished from amortized learned weights. Normalization statistics and inactive heads are excluded.
